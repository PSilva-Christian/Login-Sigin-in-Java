Login-CLI

Aplicação de autenticação via linha de comando desenvolvida para exercitar conceitos de segurança e persistência de dados. 🛠 Tecnologias e Conceitos:

Java & SQLite: Persistência robusta de dados de usuários.

Segurança (Bcrypt/Hashing): Implementação de hash de senhas para garantir que dados sensíveis não sejam armazenados em texto.

Prevenção de SQL Injection: Uso de PreparedStatements para sanitização de entradas, garantindo a integridade do banco de dados.
